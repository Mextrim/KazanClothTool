# KazanClothTool

Современный редактор одежды и текстур для FiveM, Rage MP и Alt:V на базе CodeWalker.

## Возможности

- просмотр моделей одежды в интерактивном 3D-режиме;
- редактирование свойств одежды, групп и тегов;
- одновременная работа с мужскими и женскими моделями;
- проверка текстур, полигонов и проблемных файлов;
- экспорт YDD, YTD, DDS и PNG;
- сборка ресурсов FiveM, Alt:V и Singleplayer;
- автосохранение, импорт и экспорт проектов;
- массовый выбор, копирование и удаление одежды;
- 14 тем оформления и переключение языка интерфейса: русский, украинский и английский.

## Сборка

Требуется .NET 10 SDK и Windows.

```powershell
dotnet restore .\grzyClothTool.sln
dotnet build .\grzyClothTool.sln -c Release
dotnet publish .\grzyClothTool\grzyClothTool.csproj -c Release -r win-x64 --self-contained true
```

Готовая сборка приложения находится в каталоге `..\KazanClothTool`; исходники и временные результаты сборки удаляются из рабочей папки.
