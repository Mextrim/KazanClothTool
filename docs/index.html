Быстрый старт

Запуск за несколько шагов

Kazan Cloth Tool — portable-приложение для Windows x64. Установка не требуется.

Совет: распакуйте архив в папку с правом записи и запустите KazanClothTool.exe.
  1. Скачайте portable-сборку из GitHub Releases.
  2. Распакуйте архив в удобную папку.
  3. Запустите KazanClothTool.exe.
Структура запуска 
KazanClothTool\
└── KazanClothTool.exe
