## ✨ Возможности

**Редактор одежды**
: 3D-просмотр, группировка по группам и тегам, массовый выбор, переупорядочивание перетаскиванием, дублирование на противоположный пол, зарезервированные слоты

**Текстуры**
: Импорт `.ytd`, `.dds`, `.png`, `.jpg` · встроенные карты normal и specular · оптимизация размера и сжатия **при сборке** · экспорт в `DDS`, `PNG`, `YTD`

**Контроль качества**
: Полигоны по уровням LOD, разрешение текстур, степень двойки, mip-уровни, сжатие

**Сборка ресурсов**
: FiveM, Alt:V, Singleplayer · автоматическая генерация `.meta` и метаданных каблуков

**Проекты**
: Автономные и внешние · автосохранение каждую минуту · импорт и экспорт в `.kctproject` · резервные копии и откат

**3D-просмотр**
: Вращение и масштаб · автосмена модели персонажа · экспорт всех текстур в PNG

**Интерфейс**
: 33 темы · русский, украинский и английский · переключение мгновенное, без перезапуска

**Каталог иконок**
: 7 400+ иконок Material Design Icons с поиском, выбором размера и копированием разметки по клику · *Настройки → Каталог иконок Material*

## 🚀 Быстрый старт

Portable-сборка, установка не требуется.

1. Скачайте архив из [Releases](https://github.com/Mextrim/KazanClothTool/releases)
2. Распакуйте в любую папку
3. Запустите `KazanClothTool.exe`
4. При первом запуске укажите папку проектов

Начать работу можно тремя способами:

| Действие | Когда подходит |
| --- | --- |
| **Новый проект** | Верстаете одежду с нуля |
| **Открыть набор** | Уже есть готовый аддон с `.meta` |
| **Импорт проекта** | Продолжаете чужую работу из `.kctproject` |

## 🧰 Типы сборки

| Платформа | Результат | Группы | Текстуры | Физ. ткань и вид от 1-го лица |
| --- | --- | :---: | --- | :---: |
| **FiveM** | папка + `fxmanifest.lua` | ✅ | всегда `.ytd` | ✅ |
| **Alt:V** | папка + `resource.toml` | ❌ | как в исходнике | ❌ |
| **Singleplayer** | `dlc.rpf` | ❌ | как в исходнике | ❌ |

> Папка вывода должна быть **пустой** либо уже быть папкой сборки Kazan Cloth Tool — чужие файлы программа не удаляет.

Подробно: [Wiki — Сборка ресурсов](https://github.com/Mextrim/KazanClothTool/wiki/Сборка-ресурсов).

## 🔣 Каталог иконок Material

В программу встроен просмотрщик **Material Design Icons** (набор из
[Material Design Icons в Figma Community](https://www.figma.com/community/file/878585965681562011/material-design-icons),
лицензия Apache 2.0).

- 7 400+ иконок, поиск по названию
- размер 16 / 20 / 24 / 32 / 48 px для предпросмотра и копируемой разметки
- клик по иконке копирует готовый XAML в буфер обмена
- ссылка на исходный набор в подвале окна

Открыть: **Настройки → Каталог иконок Material**.

```xml
<icons:MaterialIcon Kind="TshirtV" Width="24" Height="24" />
```

## ⚙️ Настройки

Хранятся отдельно от проектов в `%LOCALAPPDATA%\KazanClothTool\settings.json`.

| Параметр | Значение |
| --- | --- |
| Язык | русский, украинский, английский |
| Тема | 33 темы, сохраняется автоматически |
| Папка проектов | общая папка для всех проектов |
| Папка GTA V | только для 3D-просмотра |
| Лимит полигонов | 35 000 / 20 000 / 10 000 по уровням LOD |
| Макс. разрешение текстур | 1024 для diffuse, normal, specular |
| Помечать новые вещи | бейдж «НОВ» у добавленного |
| Показывать путь к вещи | полный путь в панели свойств |
| Автоудаление файлов | удалять файлы с диска вместе с вещью |

Изменение лимитов сразу перепроверяет все вещи проекта.

| --- | --- |
